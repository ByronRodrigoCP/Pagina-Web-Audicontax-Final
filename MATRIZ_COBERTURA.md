# Matriz de cobertura — Chamorro & Asociados

Esta matriz conecta cada requerimiento explícito del formulario con una implementación, prototipo o pendiente verificable.

| Requerimiento | Estado | Evidencia / ubicación |
|---|---|---|
| Auditoría, outsourcing y asesorías especializadas | **Implementado** | servicios.html |
| Noticias | **Implementado** | noticias.html |
| Biblioteca jurídica descargable y actualizada | **Arquitectura implementada** | biblioteca.html; contenido real requiere curaduría |
| Academia sincrónica/asincrónica, alumnos y certificados | **Prototipo** | academia.html |
| Carga de requerimientos de clientes | **Prototipo** | portal-cliente.html |
| IA con biblioteca y consultas básicas | **Prototipo** | asistente-ia.html |
| Calculadoras tributarias y laborales | **Prototipo con disclaimer** | calculadoras.html |
| Tienda de materiales, plantillas y servicios | **Prototipo** | tienda.html |
| Cotizador personalizado | **Prototipo** | cotizador.html |
| Herramienta integral para clientes | **Implementado en arquitectura** | Portal + biblioteca + academia + IA |

## Criterio de estados
- **Implementado:** existe una página, componente o contenido específico en el prototipo.
- **Prototipo / preparado:** la experiencia está diseñada, pero requiere backend, datos, credenciales o validación.
- **Documentado:** la arquitectura y controles están explicados, no desplegados.
- **Pendiente / no verificable:** falta información del alumno o la referencia no pudo confirmarse.
